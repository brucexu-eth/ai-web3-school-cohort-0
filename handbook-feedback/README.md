# Handbook Feedback

> 学员在学习过程中对 Handbook 的反馈汇总。
> 每条反馈包含页面链接、问题描述、建议改法和日期。

## 如何添加 Feedback

在 `handbook-feedback/` 目录下创建文件，命名格式：`YYYY-MM-DD-简短标题.md`

## 模板

```markdown
# Feedback: {标题}

- **日期**: YYYY-MM-DD
- **Handbook 页面**: https://aiweb3.school/zh/handbook/...
- **问题类型**: 错别字 / 概念不清 / 资料过期 / 结构建议 / 其他
- **问题描述**:
- **建议改法**:
- **来源**: （哪段话 / 哪个例子引起的问题）
```
